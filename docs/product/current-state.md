## 当前边界和优先缺口

安全扫描仍只处理用户明确指定且已登记/审批的目标；TCP 端口探测限定单台已登记主机，ICMP 只向已登记主机发送一次有界 echo。端口探测开放结果不会直接授权漏洞扫描。

## 2026-10-21：PostgreSQL 连接与迁移基础

`internal/repo/postgres.go` 将 PostgreSQL 迁移脚本嵌入 Server，并提供受保护 DSN 文件读取、连接池 Ping、单连接 advisory lock、空公共 schema 检查、未知/断档迁移日志拒绝和按版本执行。`internal/repo/postgres_queue.go` 已补 Server 侧核心任务队列适配器：创建任务、`FOR UPDATE SKIP LOCKED` 领取、租约续期、完成和按规则版本统计，并在适配器边界拒绝主机名、CIDR、未指定/组播地址；`internal/repo/postgres_task_projection.go` 已补任务 UI 字段、标准化块状态和 Worker advisory progress 的投影读写；`internal/repo/postgres_findings.go` 已补发现项稳定指纹、去重、生命周期、接受风险到期、事件和分页筛选适配；`internal/repo/postgres_reports.go` 已补报告模板、冻结快照、分页历史、格式复用、重试恢复和带 `SKIP LOCKED` 的生成队列；`internal/account/postgres.go`、`internal/assets/postgres.go`、`internal/assets/postgres_management.go` 和 `internal/approvals/postgres.go` 已补账号会话、资产登记/端口/业务组/CSV 摘要导入、授权范围和端口审批核心适配；规则目录投影可由 Updater 状态同步。`lab/orbstack-target/compose-postgres.yaml` 提供只绑定回环地址的 PostgreSQL 16.4 隔离夹具，可通过 `POSTGRES_DSN_FILE=/path/to/dsn make migrate-postgres` 对新建数据库执行；命令不会创建数据库、写入演示数据或切换当前 SQLite Server。当前 SQLite 仍是默认便携模式；Server 可用 `--storage postgres --postgres-dsn-file` 显式选择 PostgreSQL，未实现的接口返回能力不可用，不会回退到 SQLite。

## 2026-10-21：总览风险评分、趋势与下钻

总览页现在按 [风险评分口径](./risk-score.md) 计算 0–100 风险评分、有风险资产数和严重度分布，并提供 7、30、90 天活动系统/Web 漏洞趋势。风险业务组和风险资产表按活动发现项计算，业务组、资产、严重度和检测口径等数字可直接进入 `/findings` 对应筛选；业务组和资产筛选保存于 URL，可刷新、前进/后退并从标签移除。

## 自动综合扫描立即任务向导（2026-10-20）

`/tasks` 的自动综合扫描立即任务使用四步向导：选择一台已登记数字 IP 主机，填写现有端口策略、强度、任务排除和自定义规则，设置执行时间窗，再核对目标、有效端口预览、系统/资产/任务排除、隔离端口和时间窗后勾选运维授权。前后返回保留配置；修改配置后需要重新勾选授权。下一步只校验当前步骤，未授权或未到确认步骤不会创建任务。全端口（含自定义范围覆盖全端口）保留提交时的再次确认。

端口预览仅根据当前资产和系统策略计算，Server 继续通过原 `POST /api/v1/tasks` 重新校验和冻结目标与端口；系统策略读取失败或有效端口为空时不能从方案步骤继续。选择定时发起、模拟任务或离线输入扫描仍进入原表单，旧任务复制可继续使用。该步骤没有新增扫描方案 API 或调整 Worker 执行能力。

前端回归：在仓库根目录运行 `node web/src/pages/Tasks/policy.test.mjs`、`node web/src/pages/Tasks/wizard.test.mjs` 和 `npm --prefix web run build`。手工演示时先尝试空目标“下一步”，再选择文档保留地址段中的已登记实验资产，设置自定义范围和排除，前后返回检查值保留，确认页检查有效端口和时间窗；未勾授权应无法创建。全端口确认选择“返回修改”时不应发起创建请求。以上演示仅针对隔离实验环境。

自动综合扫描方案步骤提供“快速检测”和“标准检测”两张预置方案卡片。快速检测使用常见端口和温和强度，适合首次确认暴露面；标准检测使用常见端口加可选自定义范围和标准强度，适合日常例检。卡片只写入现有产品级端口策略、强度、排除项和规则选择，Server 仍会重新校验资产、授权、时间窗和实际端口；不把引擎命令行暴露给用户。用户可以在选择预置方案后继续调整字段，确认页显示当前方案名称和最终参数。

## 定时计划历史运行（2026-10-21）

定时计划每次由 Server 触发时写入独立的 `schedule_runs` 记录，并通过 `GET /api/v1/schedules/{id}/runs` 按时间倒序分页查询。历史只包含触发时间、任务状态、任务 ID 和安全错误摘要；任务状态从当前任务记录实时映射，任务被彻底删除后显示为“任务记录已删除”。删除计划不会删除历史，单次计划和重复计划均记录每次实际触发，错过的重复运行仍按原策略合并，不补跑。

任务中心的定时计划表提供“历史运行”入口。只读取当前用户可见的安全投影，不传递目标、输入路径、凭据或引擎输出。SQLite 与 PostgreSQL 仓储/API 测试覆盖成功触发、状态映射、分页、删除计划后保留历史和无效触发失败记录；定时/报告页面已包含在 PostgreSQL 五条核心浏览器旅程回归中。

## 2026-10-20：资产 CSV 导入最小闭环

资产页提供下载模板、选择 CSV、逐行预览、明确勾选后整批确认及刷新台账。仅管理员和安全工程师可导入；导入入口按账号角色控制。固定表头 `kind,address,businessGroup,owner`，可加最后一列 `name`；UTF-8 无 BOM，最多 1 MiB / 1000 条数据记录。支持数字 IP 主机和现有镜像仓库格式，禁止导入端口或审批字段。非法行、文件内重复及现有资产重复均显示原因，任何错误都阻止整批确认。

导入确认不会覆盖已有资产，不接受端口或授权字段；导入历史只保留操作者、数量和时间摘要，最多返回最近 200 次，不包含 CSV 原文或目标地址。PostgreSQL 核心写入和服务端分页适配已实现并在隔离夹具验证；Server 已支持显式 PostgreSQL 运行时选择，完整浏览器旅程和非核心系统适配仍待验收。CSV 导出只返回当前清册的稳定台账字段，不包含服务详情和登录入口。

## 单项漏洞指派与追加备注（2026-10-20）

详情抽屉支持指派或清除漏洞处置人，并追加不可修改的纯文本备注。处置人独立于资产负责人 Owner，仅可选当前启用的管理员/安全工程师；账户被停用后已有指派作为历史快照保留，新指派会拒绝。备注限制为 1–2000 UTF-8 字节、非空白且不含控制字符及 Unicode 行/段落分隔符（U+2028/U+2029），按作者快照和时间展示；操作统一写入 Server 并记录审计。

## 批量漏洞状态处置（2026-10-20）

漏洞表格提供显式行选择、跨分页/筛选保留选择及原状态快照，最多 100 项。工具栏选择修复中、误报、接受风险或恢复待处理，经包含 ID/原状态的确认框保存；接受风险统一填写原因和期限。状态变化后会阻止旧选择继续提交；服务端也校验 expectedStatus。失败保留选择，成功用返回记录替换并清空；操作统一写入 Server 并记录审计。
