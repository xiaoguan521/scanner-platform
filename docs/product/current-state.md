# 产品现状与规划差距

盘点日期：2026-10-19。依据当前工作区代码、路由、API 和 [产品化调整方案](../product-redesign-plan%20%281%29.md)。资产编辑/删除、授权范围编辑/撤销/删除、任务中心易用性和报告页在本次盘点中同时完善；本文件记录完善后的现状。

## 页面与路由

| 路由 | 当前用途 | 规划对应项 | 状态 |
|---|---|---|---|
| `/` | SQLite/演示数据的资产、漏洞、任务与规则摘要 | 总览 | 部分实现：有统计卡片和列表，缺趋势、快速开始、完整下钻与风险算法文档 |
| `/assets` | 主机/镜像地址台账、端口申请状态、单 IP Ping、端口探测候选批量申请；支持新增、修改、删除 | 资产 | 部分实现：无资产 CSV 导入/导出、业务组管理、详情与导入记录；缺名称、最近扫描时间和风险数列 |
| `/tasks` | 即时任务、时间窗、状态筛选、TCP 端口探测、定时任务管理 | 扫描 | 部分实现：有任务创建/取消/复制、计划增改删与启停；创建仍为单个表单，缺四步向导、扫描方案和任务详情抽屉/日志/暂停/结果导出 |
| `/findings` | 漏洞列表、严重度/状态筛选、详情展开和有限状态流转 | 漏洞 | 部分实现：缺 URL 持久筛选、详情抽屉、指派/备注/批量处置、接受风险原因与期限、单项复测入口 |
| `/reports` | 按模板及资产/业务组/任务/时间范围生成快照，可下载 Word、8 工作表 Excel、HTML、CSV、JSON | 报告 | 客户端从真实 API 列表生成；暂无服务端报告历史和异步作业记录，未提供的影响/整改/参考/证据标为“未提供” |
| `/scopes` | 授权范围申请、审批与端口审批 | 系统-授权范围 | 部分实现：支持范围申请改删撤销和端口审批；缺授权到期提醒/专门的到期筛选 |
| `/nodes` | 节点心跳、引擎和规则版本 | 系统-节点/规则库 | 部分实现：能查看状态与规则操作；缺完整节点生命周期、审计下钻和告警 |
| `/users` | 用户创建、角色和启停 | 系统-用户与角色 | 部分实现：没有删除、密码重置和系统设置页 |

当前主导航为 8 个平铺入口，尚未按规划合并为“总览、资产、扫描、漏洞、报告、系统”6 个一级模块；规划中的业务组、导入记录、扫描方案、审计日志和系统设置页面没有对应路由。

## API 与数据通道

| 领域 | 当前真实能力 | 尚缺能力 |
|---|---|---|
| 账号 | 登录、会话、管理员初始化、用户创建/角色/启停 | 密码重置、会话时长配置 |
| 资产 | 列表、增改删、单台已登记数字 IP 的有界 ICMP 提示、端口申请与审核 | CSV 预校验/确认导入、导出、业务组和导入记录资源、服务端分页/排序 |
| 扫描 | SQLite 任务、Worker 回报；自动综合扫描并发探测单台主机的授权 TCP 范围、只读 HTTP(S) 基线、自定义只读规则和可选 SSH 临时系统包采集；Nuclei、Trivy、ZAP 可独立用于旧任务/离线输入 | `scan-plans` 资源、产品化强度档位、暂停/恢复、服务/应用运行状态识别、服务器端任务级结果导出 |
| 定时 | SQLite 计划，创建/修改/启停/删除/手动触发，带时间窗 | 专门的计划运行历史与计划详情 |
| 漏洞 | 发现项列表及有限状态更新、稳定指纹去重 | 指派、备注、接受风险、批量处置、复测关联 |
| 报告 | 页面按已加载列表生成 Word、8 工作表 Excel、HTML/CSV/JSON 文件 | 服务端报告 API、可重访的历史报告、异步生成状态；弱口令与登录入口认证属性不进行主动采集 |
| 系统 | 节点、规则包、范围和端口审批 | 审计日志查询、系统设置、通知 |

业务页面通过 `useCollection` 请求 Server API；演示构建仍会从 `web/src/mock/data.ts` 使用浏览器内存数据，尚未替换为 `make seed-demo`。列表接口目前一次返回全量数据，OpenAPI DTO 和前端类型手工维护；尚未加入 OpenAPI 类型生成、统一分页参数或请求编号错误结构。

## 当前边界和优先缺口

安全扫描仍只处理用户明确指定且已登记/审批的目标；TCP 端口探测限定单台已登记主机，ICMP 只向已登记主机发送一次有界 echo。端口探测开放结果不会直接授权漏洞扫描。

如果继续按产品旅程推进，建议先完成扫描创建四步向导、资产 CSV 预览/确认和漏洞详情/处置，再补总览下钻与审计查询。报告页目前能够直接下载，但由于报告历史未落库，刷新或离开页面后需要重新生成。
