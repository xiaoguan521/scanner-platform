# 总览风险评分

总览风险评分是当前漏洞列表的可重复计算结果，范围只包含 `riskType` 为 `system` 或 `web` 的发现项。登录入口、弱口令（当前未启用）和未核实类型单独统计，不进入评分。

## 计算规则

1. 忽略 `FIXED` 和 `FALSE_POSITIVE`；`OPEN`、`REOPENED`、`IN_PROGRESS` 和 `ACCEPTED_RISK` 保留在风险范围内。
2. 按严重度累加基础分：`CRITICAL=30`、`HIGH=20`、`MEDIUM=10`、`LOW=3`、`INFO=1`。
3. `ACCEPTED_RISK` 的基础分按 25% 计入，表示风险仍存在但已有过期时间和处置记录。
4. 结果四舍五入后限制在 0–100，作为“风险评分”。评分不代表 CVSS，也不触发扫描或自动处置。

风险资产数按活动漏洞关联的 `assetId` 去重；历史数据缺少 `assetId` 时使用目标主机部分作为临时稳定键。等级分布统计所有系统/Web 发现项，保留已修复项用于历史总量对照。

## 趋势口径

7、30、90 天趋势的每个点表示该日期结束时仍处于活动范围的系统/Web 发现项数量。发现时间晚于日期结束的记录不计入；有 `resolvedAt` 且已在该日期前修复的记录不计入；没有可靠修复时间的历史 `FIXED` 记录不计入。当前实现由已加载的漏洞列表计算，后续接入服务端分页或历史聚合时必须保持同一口径。

## 下钻

总览卡片和等级数字链接到漏洞列表；业务组和资产排行通过 `businessGroup`、`assetId` 查询参数下钻。漏洞页会保留这些参数并在刷新、前进/后退时恢复，筛选结果仍由当前 Server 返回的完整列表计算。
