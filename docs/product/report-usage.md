# 资产画像、知识库与报告使用说明

只对明确授权的隔离实验目标验收。先在资产页登记数字 IP、名称、核心标记、业务组、责任人和部门等信息;自动扫描不会寻找其他主机。任务向导选择端口范围、排除和强度,全端口须确认。ICMP 未响应表示未知,后续 TCP 检测仍会进行。完成后在资产详情查看服务、版本、技术栈和登录入口。未知字段保持未知,不会凭远程横幅断言完整操作系统或防爆破能力。

发现项显示检测方式与置信度。`principle` 为原理验证、`configuration` 为配置检查、`version` 为仅版本推断、`unknown` 为历史或来源不足。只有版本号匹配时不会标成已原理验证;OpenSSH 等易受发行版回补影响的推断默认低置信度。漏洞总数只含系统与 Web 漏洞,登录入口独立计数。弱口令所有位置显示“本次未启用该检测项”,不尝试登录或默认凭据。

“知识库”支持录入和导入公开来源整理的规范 JSON。一次请求 `{"items":[...]}` 为 1–5000 条、上限 10 MiB。每条包括 `id`、`title`、`component`、`source`、`affectedRanges` 及可选中文描述/影响/修复、编号、CVSS、分类和资料链接。例如版本范围 `{"introduced":"1.0","fixed":"1.2"}` 表示含 1.0、不含 1.2;也可用含边界的 `lastAffected`,不能与 `fixed` 同用。不支持的版本格式不会强行匹配。平台不自动导入 OSV 原始格式,也不自动下载或接入 CNNVD/CNVD;外部编号字段不代表已接入该数据源。中文内容尚未覆盖的条目保留原文标记。

“报告”选择模板、格式和任务/资产/业务组/时间范围,点击生成。任务依次显示排队、生成中、就绪或失败;就绪后下载 HTML、Excel、Word、PDF、CSV 或 JSON。CSV 是漏洞明细平面文件,列与报告漏洞详情表一致;JSON 是完整冻结快照,包含资产、任务、发现项、汇总和范围。报告名称遵循“首个目标等 N 个目标_方案名_时间戳”。模板可配置公司、内嵌 Logo、页眉页脚、等级文本、安全建议和章节开关。HTML 为离线单文件,不请求远程图片或脚本;PDF 使用离线内置 CJK 字体生成 A4 文本与表格，不请求远程资源。

生成报告时冻结资产、发现与模板快照,重试仍使用原快照。任务范围使用本任务持久化的观察记录与服务识别结果;资产归属及登记信息取生成时快照。旧历史任务没有观察数据时不会伪造历史结果。生成不调用扫描器。快照最多 32 MiB,文件最多 64 MiB,超过上限须缩小范围。后台队列最多 100 个待处理报告;失败项可重试,进程重启后中断生成会重新排队。进度表示排队/开始/完成阶段,不代表精确剩余时间。

HTML 和 Word 包含八章、服务端生成图表、TOP100 表及每漏洞最多 10 个影响资产,并标注截断。PDF 保留八章的文本与表格数据，使用内置 CJK 字体并按 A4 分页。Excel 保留八张完整明细表,漏洞详情包含检测方式和置信度。六个格式使用同一快照与统计规则;分别在不同时间新建报告可能因业务数据更新而不同。CSV 对以 `=`, `+`, `-`, `@` 开头的单元格加前缀,防止被电子表格误解释为公式;JSON 使用标准 UTF-8 JSON 编码。

演示路径:

1. 资产 → 登记隔离靶机 → 扫描任务 → 自动扫描 → 常见端口并排除一个监听端口 → 开始。
2. 任务完成 → 资产详情检查服务/登录入口 → 发现项筛选版本推断并检查置信度。
3. 报告 → 选任务与默认模板 → HTML/Excel/Word/PDF/CSV/JSON 分别生成并下载 → 核对综述与明细、弱口令状态和排除清单。
4. 节点/设置 → 修改系统排除 → 新建任务确认被排除端口不会下发;隔离记录由管理员填写复核原因后解除。

逐项实现与实际验证见 [report-checklist.md](report-checklist.md)。当前通用组件识别与公开 JSON 导入不能证明任意厂商、国产数据库、中间件或发行版已获得完整漏洞覆盖。真实靶机扫描、抓包和 Office 软件排版验收仍需独立验证。
